# Access control (draft)
Owner: [OWNER REVIEW]. Production access is assigned to named individuals only, limited to the job and reviewed quarterly. Require MFA for GitHub, cloud console and identity-provider administrators. Record approval, role, date, last review and removal for each account. Remove departing people's access promptly and rotate shared or exposed credentials. Keep database migration and runtime roles separate; prohibit application roles with SUPERUSER, BYPASSRLS or schema-owner permissions. Customer workspaces are isolated by application checks and forced PostgreSQL RLS. Support access to a customer's data requires a ticket, customer authority, minimal duration, audit record and a named approver; no standing unrestricted access. Keep break-glass access time-limited, logged and reviewed after use.
