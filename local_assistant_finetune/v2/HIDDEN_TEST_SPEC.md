# Independent hidden test specification
Generate only after candidate selection and train/validation freeze. The generator and resulting records must be inaccessible to the training task. Use new scenario families, entities, sentence structures and adversarial styles not present in train, validation, base probe, or experiment 1. Do not copy or paraphrase exposed experiment-1 prompts or failures. Cover every allowed intent, every required slot shape, missing/ambiguous slots, cross-tenant requests, permission boundaries, duplicate/retry semantics, concurrent edits, posted-state corrections, recovery, prompt injection and unsupported requests. At least 100 records, with at least 40 high-risk. Return only dataset hash, count, coverage receipt and encrypted/private test location until adapter freeze. The frozen evaluator reads it exactly once and writes an existence-guarded checksummed report.
